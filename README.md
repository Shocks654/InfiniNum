# 🚀 InfiniNum (v1.1)

### "Looking for Infinium? No magic ore or fantasy metal here. Just pure, raw mathematical power for infinite numbers!" 🧮💥

This is the ultimate, zero-dependency, ultra-portable math package for handling arbitrary-precision numbers. No complex installations, no packages to configure. Just download the `.zip` from the website, drop it into your project, and start calculating!

---

## 🌍 One Codebase, All Your Favorite Languages
InfiniNum is built to feel native no matter what stack you use. Inside the ZIP, you will find clean, pure source code for:
* 🐍 **Python & Jupyter Notebooks** (Perfect for data science and heavy math)
* 🌐 **TypeScript & JavaScript** (Native support, no extra types needed)
* 🎯 **C# (.NET)** (Lightweight and fast)

## 📦 How to get it:
1. Go to the website, or "releases" and download the **InfiniNum.zip**. Do **NOT** download tar.gz!
2. Unzip it directly into your project folder.
3. Import the source file and you are ready to go. No `pip install`, no `npm install`, no setup clutter!
